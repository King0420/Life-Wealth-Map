# Life Wealth Map｜人生财富曲线图
> 可视化绘制你一生的净资产轨迹，记录高光、低谷、负债与东山再起 📈

<img width="1264" height="862" alt="image" src="https://github.com/user-attachments/assets/a5acf386-9f4c-463f-8b78-5e41dc18a197" />


一款轻量、纯前端的人生财富轨迹绘图工具。
0元为基准线，向上代表净资产，向下代表负债；你可以按年龄添加财富节点，备注人生事件（创业、暴富、亏损、负债等），自动生成属于自己的财富曲线。

## ✨ 核心功能
- 📝 自定义节点：填写年龄、财富金额，支持负数代表负债，附带事件备注
- 📊 实时可视化图表：随年龄变化的财富曲线，区分正资产/负债
- 📌 快捷操作：添加、修改、删除节点，载入示例、一键清空
- 📋 关键指标统计：自动展示最高财富、最低财富、最新节点信息
- 📦 本地存储：数据保存在浏览器本地，不上传服务器，保护隐私
- 🚀 开箱即用：纯静态页面，无需后端，直接打开 HTML 运行

## 🎯 适合谁
- 想要复盘自己过往财务起伏
- 推演未来财富规划、FIRE 退休计划
- 做财商思考、财富沙盘模拟
- 记录人生重大财务事件：创业、投资、亏损、负债、置业
